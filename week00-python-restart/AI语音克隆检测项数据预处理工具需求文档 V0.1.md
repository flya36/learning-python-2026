## 一、文档目的
本文档定义语音克隆检测项目的数据预处理工具的能力边界与数据规范，用于统一数据集格式、明确工具开发目标，支撑后续样本统计、鲁棒性实验与模型测试。
V0.1 为需求初稿，聚焦**样本统计与格式校验**核心能力，不涉及音频转码、特征提取等深度处理。

## 二、数据格式规范
### 2.1 音频基准格式
所有核心实验统一使用基准格式，保证实验变量唯一：
- **封装格式**：WAV（无损 PCM 编码）
- **采样率**：16 kHz
- **位深**：16 bit
- **声道**：单声道（mono）
- **兼容格式**：MP3、FLAC 仅用于压缩鲁棒性测试场景，不进入核心训练与基准测试集。

### 2.2 标签定义
| 标签值 | 含义 | 说明 |
|---|---|---|
| `bonafide` | 真人语音（正样本） | 真实人类录制的原始语音 |
| `spoof` | 克隆语音（负样本） | AI 生成/篡改的伪造语音 |

### 2.3 文件命名规范
单条音频文件名统一格式：`说话人ID_样本序号.wav`
- 示例：`spk001_0001.wav`、`spk001_0002.wav`
- 说话人ID统一为 `spk+三位数字`，样本序号为四位数字，便于批量解析。

## 三、数据集目录结构规范
数据集采用「标签一级目录 + 说话人二级目录」的分层结构，配套全局索引文件。
```
voice_dataset/
├── bonafide/                # 真人语音正样本
│   ├── spk001/
│   │   ├── spk001_0001.wav
│   │   └── spk001_0002.wav
│   └── spk002/
│       └── ...
├── spoof/                   # 克隆语音负样本
│   ├── spk001/
│   │   └── ...
│   └── spk002/
│       └── ...
└── metadata.csv             # 全量样本索引文件
```

### metadata.csv 字段定义
| 字段 | 说明 |
|---|---|
| file_path | 音频文件相对路径 |
| speaker_id | 说话人ID |
| label | 样本标签（bonafide / spoof） |
| duration | 音频时长（秒） |
| sample_rate | 采样率 |

## 四、V0.1 工具功能需求
### 4.1 目录遍历与文件识别
- 支持传入数据集根目录路径，自动递归遍历所有子目录
- 自动识别 `.wav` 音频文件，过滤非音频文件
- 从文件路径与文件名中解析提取：说话人ID、样本标签

### 4.2 样本统计功能
- 统计总样本数量、正负样本数量与占比
- 按说话人维度统计：每个说话人的样本数、各标签下样本数
- 统计有效文件数、异常文件数

### 4.3 结果导出
- 支持导出统计结果为 `analysis.json` 格式
- 支持导出统计结果为 `statistics.csv` 格式
- 导出内容包含：总样本数、正负样本占比、各说话人样本明细

### 4.4 基础异常处理
- 空目录、目录不存在场景的友好提示
- 非音频文件自动跳过，不中断整体流程
- 命名不规范文件计入异常统计

## 五、输入与输出定义
### 输入
- 位置参数：数据集根目录路径
- 可选参数：导出文件格式（json / csv / 全部）、导出路径

### 输出
1. `analysis.json`：结构化统计结果
2. `statistics.csv`：表格化统计结果
3. 控制台输出：统计概览摘要

## 六、V0.1 边界约束
- 不实现音频转码、重采样、格式转换功能
- 不实现声学特征提取
- 不实现图形化界面，仅提供命令行调用
- 不做音频内容合法性校验，仅做文件名与格式级校验
