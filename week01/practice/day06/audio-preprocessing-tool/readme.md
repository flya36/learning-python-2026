# 音频数据预处理工具 V0.2

用于语音克隆检测项目的音频数据集批量统计与预处理工具，支持遍历目录、自动解析文件名、统计样本分布与时长、导出JSON/CSV结果。

## 功能特性
- 批量遍历目录下所有 `.wav` 音频文件
- 从文件名自动提取 **说话人ID、样本编号、真实/伪造标签**
- 统计维度：总文件数、说话人数量、真实/伪造样本数、总时长、单说话人明细
- 双格式输出：JSON（结构化数据）+ CSV（表格明细）
- 异常处理：目录不存在、无音频文件、文件名格式错误、音频损坏均有容错
- 零第三方依赖，仅使用Python标准库

## 环境要求
- Python 3.8+
- Windows / Linux / WSL 均可运行

## 快速开始
1. 将音频文件放入 `example/` 目录，文件名格式：`说话人ID_样本编号_标签.wav`
   - 示例：`speaker01_001_real.wav`、`speaker02_003_fake.wav`
2. 运行主程序
   ```bash
   python audio_tool.py
3.统计结果将输出到 `output/` 目录：
   - `audio_stats.json`：完整结构化统计结果
   - `audio_stats.csv`：说话人明细表格
