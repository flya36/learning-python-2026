# 语音项目数据规范文档

> 版本：v1.0（2026-09-13）
> 适用范围：本组（组员1、组员2 与本机）统一遵守的数据格式标准
> 目的：确保三人协作时，输入数据、输出文件、模块接口保持一致，避免互相踩格式

---

## 1. 音频文件命名规范
所有音频样本统一按以下格式命名：

```
<说话人ID>_<标签>_<序号>.<格式>
```

| 字段 | 取值 | 说明 | 示例 |
|------|------|------|------|
| 说话人ID | 字母+数字 | 唯一标识说话人 | `speaker001` |
| 标签 | `real` 或 `fake` | real=真实语音，fake=AI克隆语音 | `real` |
| 序号 | 3位数字 | 同一说话人同标签下的递增序号 | `001` |
| 格式 | `wav` / `mp3` | 目前仅支持这两种 | `wav` |

**合法示例**：`speaker001_real_001.wav`、`speaker002_fake_003.mp3`

## 2. 数据字段定义
解析每个音频文件后，得到以下结构化字段：

| 字段名 | 类型 | 含义 | 备注 |
|--------|------|------|------|
| `file_path` | str | 音频文件绝对路径 | 由解析器自动生成 |
| `speaker_id` | str | 说话人ID | 从文件名第1段提取 |
| `label` | bool | `True`=真实 / `False`=克隆 | 从文件名第2段提取，real→True，fake→False |
| `duration` | float | 音频时长（秒） | V0.3 暂为 0.0 占位，后续接入 librosa 计算 |

## 3. 输入目录规范
```
data/test_audio/          # 所有音频样本存放于此
├── speaker001_real_001.wav
├── speaker001_real_002.wav
└── speaker002_fake_001.wav
```
- 只扫描 `.wav` 文件（V0.3）
- 目录内层级不限（支持递归扫描）

## 4. 输出文件规范
### 4.1 `output/audio_samples.csv`（样本明细）
| 表头 | 内容 |
|------|------|
| 文件路径 | 绝对路径 |
| 说话人ID | speaker_id |
| 标签 | 真实 / 克隆 |
| 时长(秒) | duration |

### 4.2 `output/audio_stats.json`（数据集统计）
```json
{
  "总样本数": 0,
  "独立说话人数": 0,
  "标签统计": {"真实语音": 0, "克隆语音": 0, "总计": 0},
  "总时长(秒)": 0.0
}
```

## 5. 模块接口约定（供组员协作）
| 模块 | 对外接口 | 输入 | 输出 |
|------|----------|------|------|
| `models.audio_sample` | `AudioSample` 数据类 | 文件路径、说话人ID、标签、时长 | 单样本对象 |
| `models.audio_sample` | `AudioDataset` 数据集类 | 样本对象列表 | 提供 add/统计/导出 |
| `core.parser` | `scan_audio_dir(dir)` | 音频目录路径 | `List[AudioSample]` |
| `core.exporter` | `export_to_csv(dataset, path)` | 数据集+输出路径 | 成功返回 True |

> 约定：组员1 新增功能请放入 `src/core/`，组员2 新增模型请放入 `src/models/`，新增通用工具放入 `src/utils/`，保持分层不混。
