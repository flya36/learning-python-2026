## 五、学习与执行规则
1. **代码原则**：先独立编写 15~30 分钟，再借助 AI 查错/解释；核心代码必须能自己复现、自己讲解
2. **Git 规范**：每个功能点至少 1 次有效提交，Commit 格式：`feat/fix/docs: 具体内容`
3. **Bug 管理**：所有问题记录「现象 → 原因 → 解决方案 → 如何避免」，形成 Bug 清单
4. **AI 使用边界**：禁止直接复制未理解的框架/库代码；禁止用 AI 替代核心逻辑编写
5. **时间分配**：普通日 5h，周四忙日 3.5h，周六 6.5h，周日 6h；优先保证核心项目产出，非核心练习可裁剪
