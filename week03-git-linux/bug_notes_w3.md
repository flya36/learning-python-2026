## 本周常见错误速查（示例）
- Linux：权限不足（Permission denied）→ 检查 `ls -l` 权限位 / `chmod` / `sudo`
- Git：`merge` 冲突 → 先 `git status` 定位冲突文件，手动解决后 `git add` + `commit`
- WSL：换行符问题 → Windows 写脚本注意 `\r\n`，可用 `dos2unix` 或 `sed -i 's/\r$//'`
