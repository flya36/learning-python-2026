# 第4周｜W3 Git + Linux + 语音项目协作 学习指南
> 计划周期：2026-09-14 — 2026-09-20

## 一、本周核心目标
1. **Linux 基础**：掌握常用命令并能在 WSL 中运行语音工具——文件操作（pwd/ls/cd/cp/mv/rm/cat/less）、文本处理（grep/find/head/tail/wc）、进程与权限（ps/top/kill/chmod/chown）、网络与压缩（ssh/curl/wget/tar）
2. **Git 协作**：掌握 clone/add/commit/push/pull/status/log 与 branch/switch/merge/conflict；完成 10 次规范提交，模拟一次多人协作冲突解决
3. **语音项目协作**：与组员 1、2 对齐进度，部署语音工具到 Linux，输出接口文档 V0.1
4. **Arkclaw 比赛**：团队首次会议，明确分工与任务清单
5. **OS 面试题 5 道**：每天 15 分钟整理 1 道，周末口述验收

## 五、学习与执行规则
1. **代码原则**：先独立编写 15~30 分钟，再借助 AI 查错/解释；核心代码必须能自己复现、自己讲解
2. **Git 规范**：每个功能点至少 1 次有效提交，Commit 格式：`feat/fix/docs: 具体内容`
3. **Bug 管理**：所有问题记录「现象 → 原因 → 解决方案 → 如何避免」，见 `bug_notes_w3.md`
4. **Linux 练习**：每学一个命令立刻在 WSL 终端执行，拒绝只记笔记不实操
5. **AI 使用边界**：禁止直接复制未理解的框架/库代码；禁止用 AI 替代核心逻辑编写
6. **时间分配**：普通日 5h，周四忙日 3.5h，周六 6.5h，周日 6h；优先保证核心项目产出
